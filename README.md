
# ERP Frontend Project

This project is an ERP frontend application developed using React, React Router, Material UI, and Tailwind CSS.

## Current Progress - First Stage

Completed the initial frontend structure and layout design for the ERP system.

### Implemented Features

- Designed the basic dashboard layout
- Created a responsive left sidebar navigation
- Added routing for all major sections using React Router
- Implemented pages for:
  - Products
  - Customers
  - Suppliers
  - Purchase Orders
  - Sales Orders
  - Invoice
  - Dashboard Summary
- Tested all routes using sample JSON data
- Structured the project components for future scalability
